# copyai image to HTML CSS

## Description

A simple project for converting images into HTML and CSS layouts.

## How to Get Started

### 1. Environment Setup

- Ensure a `.env` file is configured before starting.  
  - Create a `.env` file if it doesn’t exist.  
  - Add the required values inside it.

### 2. Run the Main Script

1. Open the `crew.py` file.  
2. Specify the path to your image in the file.  
3. Run the script using the following command:  
   ```bash
   python crew.py
   ```

### 3. Use the Graphical User Interface (GUI)

If you prefer using a GUI, follow these steps:

1. Navigate to the `gui` folder.  
2. Launch the GUI using the following command:  
   ```bash
   python copyai.py
   ```

## Requirements

- Libraries listed in the `requirements.txt` file.
